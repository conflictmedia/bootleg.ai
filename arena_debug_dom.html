For this class of issue, check that the plugin/site enforces:

  1. Spin eligibility on the server, not in JavaScript.
  2. One spin per qualifying event using atomic database updates.
  3. Rewards generated server-side only.
  4. Client requests cannot submit reward amounts, coupon values, or points directly.
  5. AJAX/REST endpoints validate nonce, authentication, user capability, and rate limits.
  6. Reward redemptions are tied to user ID, order ID, and a single-use event token.
  7. Repeated requests are logged and throttled.
  8. WooCommerce coupons/points cannot be created by unauthenticated users.
  9. Plugin and WooCommerce are fully updated.
  10. Suspicious duplicate rewards are periodically audited.
